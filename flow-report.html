RealTemp Flow Report

Problem

Forecast had become a catch-all screen: 24-hour trend, sweat, radar, and shade all lived in one vertical stack. That made every new weather feature feel like more scrolling.

Change Shipped

  • Keep Now focused on the current decision and transparent math.
  • Keep Forecast focused on time: sweat, safe window, hourly list.
  • Move Radar and Shade into a dedicated Maps tab.
  • Move visual style choices into Settings so the header stays action-oriented.

Style Direction

Default style moves away from neo-brutal sharpness toward a softer iPhone-native surface. Classic keeps the older square treatment available, and Signal adds a cooler weather-instrument feel.

Remaining Risk

Watch next: Tune is still the densest screen because it contains climate, body, and push controls. If it grows again, split Body and Alerts out before adding more content.
